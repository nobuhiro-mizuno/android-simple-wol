# 品質確認

## 自動確認

- `./gradlew testDebugUnitTest`：MAC・IPv4・ポートの検証、マジックパケットの長さと内容。
- `./gradlew assembleDebug`：Manifest、リソース、Java のビルド。
- `./gradlew lintDebug`：Android 固有の静的解析。

## 実機確認（Android 8 以上と新しい Android で各一回）

1. 初回起動で空状態が整い、PC を追加できる。
2. 不正な MAC、IPv4、ポートを保存できず、修正できる。
3. アプリの起動ボタンから対象 LAN に送信できる。パケット受信ツールで 102 バイトの内容を確認する。
4. 1 × 1 ウィジェットを追加し、PC を選択してタップ送信できる。複数ウィジェットが別々の PC を指せる。
5. PC の編集内容がウィジェットに反映される。削除後のウィジェットから設定画面に移れる。
6. 画面回転、アプリ再起動、端末再起動後も設定とウィジェットが保たれる。
7. 小画面、文字拡大、ダークモードで文字欠けや押しづらさがない。

## 完了条件

仕様の基本操作が実装され、自動確認が合格し、実機確認の結果が記録されていること。実機または SDK がない環境では、その項目を「未確認」と明記し、リリース判断を保留する。
