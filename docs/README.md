# 文書の入口

| 文書 | 用途 |
| --- | --- |
| [product.md](product.md) | 利用者の操作、入力、境界条件 |
| [decisions.md](decisions.md) | 技術・UX の判断と理由 |
| [development.md](development.md) | 構成、実装規約、変更手順 |
| [quality.md](quality.md) | テストとリリース前確認 |
| [work-plan.md](work-plan.md) | 小単位の進捗と検証結果 |

人と AI エージェントは `AGENTS.md` を入口に、上の順に関係文書を確認する。仕様の正本は `product.md` とし、実装と食い違ったら仕様を確認して修正する。未決事項は `decisions.md` に記録してから進む。
